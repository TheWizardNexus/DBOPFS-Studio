## Description

```text
Your DBOPFS data, made legible.

DBOPFS Studio 0.1 is a local-first Chromium workspace for inspecting and managing DBOPFS applications, tables, and records stored in the selected site's Origin Private File System (OPFS).

Open Studio from the toolbar for the current site, or launch it for the page inspected in DevTools. Review storage usage, quota, persistence, and DBOPFS totals; browse and filter records; edit supported text; validate JSON; render Markdown locally; preview browser-supported media; open PDFs in Chromium's native viewer; create tables and records; import files into a table; export an application; print supported formats; and delete individual records with exact-name confirmation.

DBOPFS Studio requires no Studio account, analytics service, or automatic cloud sync. Inspected content is processed in the browser unless you deliberately export, download, copy, or print it.

Chrome and Microsoft Edge are first-class targets. Other compatible Chromium browsers may work when they provide the required Manifest V3, DevTools, OPFS, and storage APIs.
```
